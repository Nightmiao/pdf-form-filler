## 二、打印到底坏在哪（已修）

### 根因：整页内容向右下平移了一个页边距，右下角还被裁掉

`print_helper.py` 原来这么做：

```python
paper = printer.pageRect(printer_device_pixel())   # 例如 (167,167,9583,13699)
painter.translate(paper.x()/scale + ..., paper.y()/scale + ...)
```

但**实测证明**：`QPainter` 画在 `QPrinter` 上时，它的坐标原点**本来就是"可打印区左上角"**，
`pageRect()` 里的 x/y 是"可打印区相对纸张边缘"的偏移 —— 两者是同一个东西，
再叠加一次就等于把整页往右下推了一个页边距。

我用基准方块实测过这台机器上的实际偏差：

| | 修复前 | 修复后 | 理想值 |
| --- | --- | --- | --- |
| 左上基准方块期望 (100,100)pt | (116.5, 120.8) → **偏 +3.5mm / +3.5mm** | (106.8, 110.8) | (106.7, 110.8) |
| 内容包围盒 | (116.8,120.8)-(**585.5**,828.2) 右边被裁 | (106.5,110.8)-(575.2,818.2) | (106.7,110.8)-(575.3,818.2) |

修复后落点误差 **< 0.1mm**。

A4 上偏 3.5mm 看起来不多，但真实打印机硬边距通常 4~6mm，偏移量会更大，
而且是**整体错位 + 右下裁边** —— 表格最下面一行会被切掉，套打（打印到预印表格）也完全对不上。

> 为什么以前的回归测试没发现：旧用例只检查"打印页面上有没有暗像素"，
> 内容平移 10pt 照样有暗像素，所以一路绿灯。
> 新增的 `tests/print_accuracy.py` 用两个已知位置的基准方块反算实际落点，
> 误差超过 0.42mm 直接判定失败。

### 顺带修掉的其他"打印不了"原因

1. **点了打印毫无反应**：无控制台的 EXE 里，打印过程中抛的异常直接消失在 Qt 槽里，
   屏幕上什么都不发生。现在整个打印流程包了异常兜底，任何失败都会弹框说明原因。
2. **多页表单打印时界面像卡死**：整页 300 DPI 渲染期间不处理事件，老机器上要等十几秒。
   现在每页之间 `processEvents()` + 等待光标，界面不假死。
3. **没有打印机 / 驱动拒绝新页**：以前静默失败，现在明确提示，并告诉用户可以改用「导出 PDF」。
4. **打印机 DPI 过高导致空白页**（上一版已修）：渲染分辨率封顶 300 DPI，失败自动降级 150 DPI。

## 三、界面改了什么

| 问题 | 修复 |
| --- | --- |
| 白色卡片/工具栏里出现**灰色方块** | 全局样式表的 `QWidget{background}` 传染给了 QLabel，补 `QLabel{background:transparent}` |
| 首页空状态是个**空心方框** | 界面用了 emoji，而 Win7 没有 Segoe UI Emoji 字体（Win8 才有）。所有图标改为 QPainter 自绘，任何系统都一致 |
| 提示文字**对比度太低**（2.87:1） | 灰阶调深到 4.5:1 以上；引导页小圆点从几乎看不见的 #D5DAE1 改成 #B0BAC6 |
| 右侧按钮**三行中缝对不齐**（113\|161 / 135\|135 / 190\|120） | 改用两列 QGridLayout，中缝统一 |
| **属性区被截断**，字段列表占一大片空白 | 列表限制高度（90~190px），高度留给 10 行属性表单 |
| 画布上的**字段名小到看不清**（约 5px） | 标签字号按场景比例换算，和填写文字一致 |
| 缩放按钮 **"−" 和 "＋" 宽度不一致** | 统一成 ASCII "-" / "+" |
| 滚动条只有 6px 抓不住 | 加粗到 13px，滑柄最小 36px；补全 hover/pressed/disabled 状态 |
| 模板名太长被硬切 | 改为显示省略号 |

## 四、Win7 上专门做的适配

- **DPI 感知**：启动时声明 DPI 感知。不声明的话，Win7 设成 125% 缩放时系统会把界面虚拟化放大，
  逻辑分辨率变成约 819x614，**比窗口最小尺寸还小，右侧面板永久跑到屏幕外**。
- **小屏自适应**：窗口按屏幕可用区域决定大小（不再硬编码 1280x800）；
  宽度小于 1180px 时左侧缩略图栏自动收起（状态栏右下角「显示缩略图」或 Ctrl+B 开关）。
  1024x768 上实测**零溢出** —— 以前「保存」「去填写」「调整设计」会被塞进 "»" 溢出菜单，用户根本找不到。
- **不依赖 emoji 字体**：见上表。
- 窗口最小尺寸从 1024x680 放宽到 940x600，125% 缩放下也能完整显示。

## 五、内置自检（重要）

如果单位电脑上打印还是不对，**先跑自检**，不用装任何调试工具：

双击 EXE 后：首页 →「**运行自检**」按钮；
或在快捷方式「目标」末尾加 ` --diagnose` 再双击。

程序会在桌面生成 **`狸猫猫表单-自检报告.txt`**，包含：
运行环境、屏幕与 DPI、中文字体是否存在、已安装打印机列表、默认打印机、
可打印区的实测值，以及**一次完整的打印落点自检**（走真实打印管线输出到临时 PDF、
量出基准方块的实际落点误差，不弹对话框、不浪费纸）。

报告最后一行的「落点判定」如果是"正常（误差 < 0.5mm）"，说明这台机器的打印链路没问题，
问题就在打印机驱动/纸张设置上；如果是"异常"，把整份报告发我即可定位。

## 七、到单位后的建议操作顺序

1. 双击 EXE → 首次会出 3 步引导，看一遍 → 进首页；
2. 首页 →「运行自检」→ 看弹窗说的"打印落点自检：正常"，报告顺手留着；
3. 「新建模板」选一张真实的 PDF 表单 → 拖几个框 → 「去填写」→ 填完；
4. 先「导出 PDF」核对中文、勾选框 √、旋转角度；
5. 再「打印」到真实打印机，**重点看右下角有没有被切掉、内容有没有整体偏移**；
6. 都没问题就可以放心用了。

有异常就把桌面上的自检报告发回来。
