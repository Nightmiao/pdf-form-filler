狸猫猫表单 —— 使用说明
========================================

【这是什么】
一款纯本地的 PDF 表单填写工具：给 PDF 表单画好填写框，
之后就能反复快速填写、保存草稿、导出 PDF 或直接打印。
原始 PDF 文件永远不会被改动，所有数据都存在本机。

【怎么用：三步】
1. 新建模板：点「新建模板」，选择一张 PDF 表单；
2. 设计字段：按住鼠标左键在表格空白处拖拽画框，在右侧设置名称、类型、是否必填等；
3. 填写导出：点「去填写」，按 Tab 依次填写，完成后导出 PDF 或直接打印。
首次打开有 3 步图文引导；首页的「使用说明」可随时再看。

【快捷键】
Tab / Shift+Tab  下一个 / 上一个字段
Ctrl+S           保存（设计模式存模板，填写模式存草稿）
Ctrl+P           打印          Ctrl+Z / Ctrl+Y  撤销 / 重做
Ctrl+滚轮        缩放          Ctrl+0           适应窗口
Ctrl+B           显示 / 隐藏左侧缩略图栏

【打印】
打印按「等比缩放、居中铺满可打印区」输出，四边留白对称。
如果打印出来有问题（空白、偏移、缺边），请先做一次自检：
   在程序快捷方式上点右键 → 属性 → 在「目标」末尾加一个空格和 --diagnose → 确定
   然后双击该快捷方式；程序会在桌面生成「狸猫猫表单-自检报告.txt」，
   把它发给开发者即可定位问题。
程序内也可以：首页 →「运行自检」。

【打印偏移是怎么修的】
旧版本把打印机的页边距当成画笔偏移量叠加了一次，导致整页内容
向右下平移一个页边距（A4 约 3.5mm，真实打印机 4~6mm），右下角还会被裁掉。
现版本改为在画笔自己的逻辑页面里居中，实测落点误差小于 0.4mm。

【界面适配】
程序启动时会声明 DPI 感知，125% 缩放下界面不会被拉伸模糊；
窗口按屏幕大小自动决定尺寸；屏幕宽度小于 1180px 时左侧缩略图栏
自动收起（状态栏右下角或 Ctrl+B 可随时开关），
保证 1024x768 上「保存」「去填写」等按钮也直接可见。

【数据保存在哪】
%USERPROFILE%\.form-filler\data
备份/迁移：直接拷贝这个文件夹，换电脑后原样放回即可恢复。

【怎么卸载】
双击安装目录下的「卸载.bat」，确认后自动删除程序目录和桌面快捷方式。
填写的数据在 .form-filler 文件夹里，需要彻底清理时请手动删除。

【常见问题】
· 双击无反应：先装 VC++ 2015-2019 运行库（多数系统已自带）。
· 杀毒软件误报：单文件 EXE 常见误报，添加白名单即可。
· 导出的 PDF 中文空白：C:\Windows\Fonts\simsun.ttc 被精简系统删了，
  从别的机器复制一份即可。
· 提示缺少 api-ms-win-crt-*.dll：装 KB2999226（UCRT）补丁。
